# 📚 خلاصه‌یار کتاب (Book Summary App)

اپلیکیشن **موبایل اندروید** برای ضبط صوتی خلاصه روزانه کتاب‌ها، تبدیل خودکار صوت به **متن فارسی**، نگه‌داری صوت و متن، خروجی نهایی هر کتاب، و گزارش ماهانه/سالانه.

> ⚠️ این پروژه یک **اپلیکیشن واقعی موبایل (Flutter / Android)** است، نه نسخه وب.

---

## 🧱 فناوری‌ها

- **Flutter** (اندروید) + زبان Dart
- پایگاه داده محلی: `sqflite`
- ضبط صدا: `record` (فرمت **WAV، ۱۶kHz، مونو** برای سازگاری با تبدیل گفتار و ادغام ساده)
- پخش صدا: `just_audio`
- تبدیل صوت به متن فارسی:
  - **پیش‌فرض (آفلاین):** `vosk_flutter` با مدل فارسی (Vosk Persian)
  - **اختیاری (آنلاین، دقت بالاتر):** OpenAI Whisper API
- تاریخ شمسی: `shamsi_date`
- نمودار گزارش: `fl_chart`
- خروجی PDF/متن: `pdf`, `share_plus`
- پشتیبان: `archive` (ZIP) + `path_provider` + `file_picker`
- عکس جلد: `image_picker` (انتخاب از گالری)
- ظاهر: Material 3 + `google_fonts` (یا فونت وزیرمتن/ایران‌سنس داخل پروژه) + `flutter_animate`

## 🎨 طراحی و ظاهر برنامه

**اصول کلی**
- Material 3 با گوشه‌های گرد، سایه‌های ملایم و فضای خالی کافی
- راست‌به‌چپ (RTL) کامل و فونت فارسی مدرن (وزیرمتن)
- تم روشن و تاریک، با تغییر خودکار بر اساس تنظیم گوشی
- رنگ اصلی: سبز زمردی یا نیلی عمیق، با رنگ تأکید طلایی/کهربایی

**صفحه‌ها**
- **خانه:** کارت «در حال مطالعه» با جلد بزرگ، دکمه ضبط شناور (FAB)، لیست جلدها به‌صورت شبکه‌ای (قفسه کتاب)
- **صفحه کتاب:** جلد بزرگ بالا با پس‌زمینه محو، نوار پیشرفت، لیست خلاصه‌ها به ترتیب تاریخ
- **ضبط:** دکمه بزرگ میکروفون با انیمیشن موج صدا و زمان‌سنج
- **جزئیات خلاصه:** پخش‌کننده صوت بالا و متن فارسی خوانا پایین، قابل ویرایش
- **گزارش‌ها:** نمودار ستونی ماهانه، نمودار سالانه، ردیف جلدهای تمام‌شده
- **پشتیبان:** کارت ساده با دکمه «ساخت پشتیبان» و «بازیابی»

**جزئیات ظریف**
- انیمیشن نرم هنگام تغییر صفحه و باز شدن جلد (Hero animation)
- رنگ پس‌زمینه صفحه کتاب از رنگ غالب جلد گرفته می‌شود (`palette_generator`)
- حالت خالی (Empty State) با تصویر و پیام دلنشین

## ⚙️ ساخت خودکار APK با GitHub Actions

فایل `.github/workflows/build-apk.yml` را بسازید:

```yaml
name: Build APK

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: "17"

      - uses: subosito/flutter-action@v2
        with:
          channel: stable

      - run: flutter pub get
      - run: flutter build apk --release

      - uses: actions/upload-artifact@v4
        with:
          name: app-release
          path: build/app/outputs/flutter-apk/app-release.apk
```

بعد از هر تغییر، از تب **Actions** فایل APK را دانلود و روی گوشی نصب کنید.

## 📱 توسعه فقط با گوشی (بدون کامپیوتر)

1. ریپو را در GitHub بسازید و این فایل را به‌عنوان `README.md` بگذارید
2. از منوی **Code ← Codespaces** یک Codespace بسازید (محیط کد داخل مرورگر)
3. در ترمینال Codespace اجرا کنید:
   ```bash
   flutter create --org com.example --project-name book_summary_app .
   ```
4. کدها را بنویسید و commit کنید
5. Actions به‌صورت خودکار APK می‌سازد؛ آن را دانلود و نصب کنید
